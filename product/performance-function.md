# Performance Function

Performance should become a transferable company function with:
- clear owner,
- clear outcome,
- documented decision logic,
- reusable skills/SOPs,
- data definitions,
- escalation rules.

Pascal may initially own/co-own:
- media-buying strategy,
- testing methodology,
- performance interpretation,
- performance-focused customer calls,
- training the performance-analysis skill.

The company should gradually own the process even when an expert improves it.
