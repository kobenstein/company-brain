# Agent Rules

1. Treat the Company Brain as durable company memory, not chat history.
2. Write canonical knowledge in English.
3. Preserve source/date/confidence whenever available.
4. Never convert one observation into a core truth.
5. Never silently change strategy, governance, ownership, compensation or legal/financial truth.
6. Keep customer-specific confidential knowledge separate from general company IP.
7. Prefer the smallest relevant file update.
8. Use meaningful Git commits.
9. Planned automations are not deployed automations.
10. If current evidence conflicts with old material, update canonical state and preserve provenance in Git/source material.
