# Flywheels & Moat

## Distribution flywheel
Useful public work → relevant audience → conversations → customers → real examples → better distribution.

## Product flywheel
Customer work → outcome/taste/performance data → reusable learning → better system → better outcomes → more usage/data.

## Support/operations flywheel
Questions/exceptions → structured resolution → better skills/SOPs/agents → fewer repeated tasks.

## Potential moat
Not model access.
Potential compounding assets:
- customer-specific taste history,
- creative-performance learning,
- documented expert decision logic,
- workflow integrations,
- distribution,
- trust,
- proprietary outcome history.

A dataset is only a moat if it is hard to recreate and materially improves outcomes.
