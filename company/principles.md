# Company Principles

## CORE --- CEO Simplicity

Reduce every recurring process to the smallest possible number of human
decisions. Complexity belongs inside the system, not inside the CEO's
head.

## CORE --- CEO Exception Principle

Show the CEO only what requires judgment, approval or meaningful
attention.

## CORE

AI handles processes; humans handle judgment.

## CORE

Manual once → observe repetition → automate.

## CORE

Company knowledge, skills, data and processes must remain portable
across model vendors and personal accounts.

## CORE

Exit-ready by design: optimize for transferability without sacrificing
product-market fit.

## CORE

Idea, hypothesis, decision and validated learning are different
epistemic states.
