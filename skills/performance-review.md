# Skill — Performance Review

1. Confirm business objective and attribution definition.
2. Check data sufficiency and anomalies.
3. Separate creative signals from audience/offer/landing-page effects where possible.
4. Label observation vs interpretation.
5. Propose the smallest next creative test.
6. Store reusable learning only when evidence justifies it.
7. Respect Impact Performance Governance.

Never treat one metric movement as causal proof without appropriate evidence.
