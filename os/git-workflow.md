# Git Workflow

A Git commit is a snapshot of the whole Company Brain.
Git still tracks exactly which individual files and lines changed.

## Commit prefixes
- `decision:`
- `learning:`
- `research:`
- `governance:`
- `customer-<name>:`
- `archive:`
- `os:`

## Review policy
Routine knowledge may be committed automatically under `os/session-sync.md`.
Core strategy, governance, ownership and high-impact changes should be proposed for review.

- `v0.1-import`
- `v0.2`
- `v0.3-english-canonical`
